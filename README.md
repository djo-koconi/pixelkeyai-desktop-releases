# PixelKeyAI desktop downloads

Installers and update packages for the PixelKeyAI desktop app. Instructions and screenshots: https://pixelkeyai.com/desktop

## Download the latest version

| System | File |
|---|---|
| Windows 10 and 11 | [PixelKeyAI-setup.exe](https://github.com/djo-koconi/pixelkeyai-desktop-releases/releases/latest/download/PixelKeyAI-setup.exe) (or the [.msi](https://github.com/djo-koconi/pixelkeyai-desktop-releases/releases/latest/download/PixelKeyAI.msi)) |
| Mac (Apple silicon and Intel), being tested | [PixelKeyAI.dmg](https://github.com/djo-koconi/pixelkeyai-desktop-releases/releases/latest/download/PixelKeyAI.dmg) |

All files, including older versions, are on the [Releases page](https://github.com/djo-koconi/pixelkeyai-desktop-releases/releases).

The installers are not signed with a paid publisher certificate yet, so Windows and macOS show a warning the first time you open the app. On Windows press More info, then Run anyway. On a Mac, Control-click the app, choose Open, then Open again.
